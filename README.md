# Мамчкин и Папчкин

Семейная карточная игра для двух родителей и маленького Босса. 70 карт: 30 испытаний, 20 карт заботы, 20 наград. Билеты, откуп, способности, история, достижения, подсказки, музыка и звуки.

## Файлы
- `index.html` — вся игра (стили, логика, карточки).
- `emblem.png` — эмблема со львами для рубашки карт.

## Публикация на GitHub Pages
1. Settings → Pages.
2. Source: Deploy from a branch. Branch: `main`, папка `/ (root)`.
3. Через минуту-две игра откроется по ссылке `https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`.

## Обновление
Замените файл `index.html` (или `emblem.png`) в репозитории, Pages обновится сам.

## Сохранения и приватность
Прогресс хранится только в браузере устройства (localStorage). Микрофон используется на карте №21 для определения голоса, аудио не записывается и никуда не отправляется.
