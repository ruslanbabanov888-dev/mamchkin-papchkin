Политика конфиденциальности

Дата вступления в силу: 16 ноября 2026 года

Настоящая Политика описывает порядок обработки и защиты персональных данных при использовании приложения «Мамчкин и Папчкин» (далее — Приложение).

1. Оператор

Оператор: Бабанов Руслан Асылбекович

Электронная почта для обращений: Babanov.R.A@yandex.ru

Приложение доступно через платформу VK Mini Apps и по прямой ссылке на GitHub Pages: открыть приложение.

2. Какие данные обрабатываются

2.1. Игровые сведения. Пользователь может вводить игровые имена или псевдонимы участников. Приложение также сохраняет игровые сведения: очки, состояние партий, выбранные колоды, настройки и прогресс. Пользователю рекомендуется не указывать в игровых именах фамилии, телефоны, адреса и другие сведения, позволяющие установить личность.

2.2. Технические сведения. При обращении к Приложению платформы и хостинговые сервисы могут обрабатывать технические данные, необходимые для предоставления доступа и обеспечения безопасности, например IP-адрес, сведения о браузере и устройстве, время обращения и технические журналы. Такие сведения обрабатываются соответствующими поставщиками сервисов по их правилам.

2.3. Микрофон. В испытании «Евровидение для Босса» Приложение может запросить разрешение на доступ к микрофону. Микрофон используется для анализа голосовой активности в реальном времени. Приложение не создаёт аудиозапись, не сохраняет и не отправляет аудио Оператору. Доступ предоставляется только после разрешения пользователя. При отказе соответствующее испытание может быть недоступно.

2.4. Фото, видео и другие материалы. Приложение не предусматривает загрузку пользовательских фотографий, видеозаписей или аудиофайлов на сервер Оператора. Материалы, создаваемые в режиме «Сохранения», пользователь хранит самостоятельно на своём устройстве.

3. Цели обработки

  • обеспечение работы игровых функций и сохранение игрового прогресса;
  • синхронизация игровых сохранений в версии VK Mini Apps;
  • сохранение пользовательских настроек;
  • работа испытаний, использующих микрофон;
  • обеспечение стабильности и безопасности Приложения;
  • рассмотрение обращений пользователей и исполнение требований законодательства.

4. Способы и места хранения

4.1. GitHub Pages. При запуске по прямой ссылке игровые данные сохраняются в локальном хранилище браузера (localStorage) на устройстве пользователя. Оператор не получает автоматического доступа к содержимому этого локального хранилища.

4.2. VK Mini Apps. В версии внутри VK игровые данные сохраняются в локальном хранилище браузера и могут синхронизироваться с помощью VK Storage через VK Bridge. Синхронизация предназначена для сохранения и восстановления игрового прогресса. При этом данные передаются инфраструктуре VK; обработка данных самой платформой регулируется также документами VK.

4.3. Хостинг. Версия по прямой ссылке размещается с использованием GitHub Pages. При обращении к сайту GitHub и используемая им инфраструктура могут обрабатывать технические сведения соединения в соответствии с документами этого сервиса.

5. Передача данных третьим лицам

Оператор не продаёт персональные данные пользователей. Для работы Приложения используются платформенные и хостинговые сервисы, в частности VK — для запуска версии VK Mini Apps и работы VK Storage, а также GitHub — для размещения версии на GitHub Pages. Эти сервисы могут самостоятельно обрабатывать технические данные в рамках своей инфраструктуры и применимых к ним документов.

6. Сроки хранения и удаление

Игровые данные хранятся в используемом механизме хранения до их удаления пользователем либо до прекращения необходимости в их обработке.

  • В версии GitHub Pages пользователь может очистить данные сайта в настройках браузера или воспользоваться функцией сброса игрового прогресса.
  • В версии VK Mini Apps пользователь может воспользоваться функцией полного сброса игры внутри Приложения.

Запросы об удалении персональных данных, обрабатываемых Оператором, можно направить на Babanov.R.A@yandex.ru. Запросы рассматриваются в соответствии с законодательством Российской Федерации. Удаление данных, которые самостоятельно обрабатываются платформами, может потребовать отдельного обращения к соответствующей платформе.

7. Защита данных

Оператор принимает необходимые меры для защиты обрабатываемых им персональных данных от неправомерного доступа, изменения, раскрытия, уничтожения и иных неправомерных действий.

8. Права пользователя

Пользователь вправе получать информацию об обработке относящихся к нему персональных данных, требовать их уточнения, блокирования или удаления в предусмотренных законом случаях, отозвать согласие, если обработка основана на согласии, а также обратиться с жалобой в уполномоченный орган по защите прав субъектов персональных данных.

Обращения Оператору направляются по адресу: Babanov.R.A@yandex.ru.

9. Изменение Политики

Оператор может обновлять настоящую Политику при изменении функциональности Приложения, способов хранения данных, состава обрабатываемых сведений или требований законодательства. Актуальная редакция размещается по постоянной общедоступной ссылке.
